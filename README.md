# ShoesFitness

**Performance, estilo e inovação para acompanhar cada treino.**

Na ShoesFitness, desenvolvemos e selecionamos calçados esportivos pensados para oferecer conforto, desempenho e resistência em todos os seus desafios. Além dos calçados, você pode complementar suas compras com produtos que auxiliam na musculação e na evolução dos seus treinos, encontrando também uma grande variedade de roupas e acessórios fitness para completar seu estilo e potencializar sua rotina de exercícios.

## Sobre o projeto

Página de uma loja virtual de calçados e artigos fitness, feita com HTML e CSS puros, sem frameworks.

**Seções da página:** cabeçalho com busca e navegação, banner principal, benefícios, categorias, produtos em destaque, coleções (masculino, feminino, corrida, academia e casual), avaliações, newsletter e contato.

## Tecnologias

- HTML5
- CSS3 (layout responsivo com media queries)

## Como executar

Não precisa instalar nada. Baixe ou clone o repositório e abra o arquivo `index.html` no navegador.

```bash
git clone https://github.com/LucasFilipe1/ShoesFitness.git
cd ShoesFitness
# abra o index.html no navegador
```

## Estrutura do repositório

```
ShoesFitness/
```
